# Number Guessing Game

## Description

Number Guessing Game is a simple Java console-based game. The computer generates a random number between 1 and 100, and the player tries to guess the correct number within 7 attempts.

## Features

- Random number generation from 1 to 100
- Maximum 7 attempts per round
- Too High and Too Low hints
- Attempt counter
- Correct answer notification
- Score calculation
- Multiple rounds
- Play Again option
- Final score display

## Technologies Used

- Java
- Scanner
- Random
- Loops
- Conditional Statements
