# Number Guessing Game

## Introduction

Number Guessing Game is a simple Java console-based game where the computer generates a random number between 1 and 100. The player has a limited number of attempts to guess the correct number.

## Features

- Random number generation from 1 to 100
- Maximum 7 attempts per round
- Too High and Too Low hints
- Correct answer notification
- Attempt counter
- Score calculation
- Multiple rounds
- Play Again option
- Final score display

## Technologies Used

- Java
- Scanner
- Random
- Conditional Statements
- Loops

## How to Run

Compile the program:

javac NumberGuessingGame.java

Run the program:

java NumberGuessingGame

## How to Play

1. Run the program.
2. Enter a number between 1 and 100.
3. Follow the Too High or Too Low hints.
4. Guess the number within 7 attempts.
5. Choose whether to play another round.

## Project Outcome

The project demonstrates basic Java programming concepts such as loops, conditional statements, user input, random number generation, and score tracking.
