# ATM Interface

## Description

ATM Interface is a simple Java console-based application that simulates basic ATM operations.

## Features

- User ID and PIN authentication
- Maximum 3 login attempts
- Transaction history
- Cash withdrawal
- Cash deposit
- Money transfer
- Balance checking
- Insufficient balance validation
- Exit option

## Technologies Used

- Java
- Scanner
- ArrayList
- Loops
- Conditional Statements
- Methods
